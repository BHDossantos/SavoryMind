# Nocturna audit: 2026-11-11

Scope: the existing Nocturna implementation under SavoryMind, based on
`claude/nocturna-night-planning-app-l6Rut` at
`e8062e10b95fe76becdbfe456ae8bc0792c2e7e5`. Unrelated SavoryMind code is unchanged.

## Repairs in this change

- Pin mobile React DOM to the Expo SDK 54 React version; install the missing web
  runtime, development client, and Babel preset. Upgrade Zustand to its
  React-19-compatible major. Regenerate the lockfile without legacy peer flags.
- Include the sibling shared directory in Metro's watch folders. Type checking
  alone did not detect the prior runtime bundling failure.
- Use sessionStorage for mobile-web authentication, while retaining SecureStore
  on native platforms. SecureStore alone cannot persist tokens on web.
- Require authenticated payment checkout/confirmation; reject client-supplied
  prices and unknown purposes; check linked plan/booking ownership; restrict
  venue subscriptions to partner/admin accounts.
- Disable mock checkout/confirmation outside dev/development/test. Production
  refuses default/short JWT signing keys and default seeded admin passwords.
- Surface checkout errors and disable repeated purchase clicks in the web UI.
- Update Next from 14.2.13 to 15.5.29 and Playwright to 1.65.0; migrate
  dynamic route parameters and viewport metadata; generate route types before
  TypeScript checks. Pin patched PostCSS across the dependency tree.
- Add payment/config regression tests, delayed-payment settlement checks, CI
  Expo dependency/bundle checks, and a hosted Chromium end-to-end job.
